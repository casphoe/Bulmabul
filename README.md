부루마불 형식 게임을 만들고 있습니다.

제작완료 된 기능
1) FireBase를 통한 로그인 / 회원가입 기능 (로그인 정보는 암호화된 Json 정보로 넘겨주기 - FireBase DataBase에 저장) / 로그아웃 / 회원 탈퇴(FireBase DataBase 삭제 & Authentication 삭제)
2) 한국어 / 영어 Toggle 기능
3) 방 만들기 기능 (개인전,팀전,맵 선택) 방 만들 시 방에 참여하고 다른 유저가 로그인해서 로비 씬에 들어가면 방 리스트에 방이 보여줘야하는 기능
4) 방 검색 기능 & 방 정렬(최신순, 가나다순(한글 우선 그 다음 영어 그다음 숫자 순으로 정렬))
5) 프로필 수정 작업(닉네임 변경, 비밀번호 변경, 프로필 사진 변경)
6) 방 나가기 & 리더 넘기기 & 준비하기
7) 전체 채팅, 파티 채팅
8) 친구 시스템 (수락 & 거절 & 삭제)
9) 친구 채팅
10) 주사위 뽑기(재화를 사용해서 1뽑,10뽑기)
11) 인벤토리 창(주사위 장착)
12) 출석 보상
13) 친구 프로필 보기
14) 방에서 친구 초대 (초대 수락 & 초대 거절)
15) 방에서 게임 준비 완료 되었을 경우 방장이 시작하면 게임 씬으로 이동
16) 게임 맵 생성
17) 게임 일시정지
18) 내 차례 일 때 홀,짝을 선택해서 주사위 게이지를 통한 주사위 굴리기
19) 주사위 굴러간 값에 따라서 플레이어 Pawn 이동
20) 땅 구매 & 건물 짓기
21) 게임 이탈 패널티 및 승패 처리 시스템
22) 적 땅 도달 시 통행료 지급 & 땅 인수 & 건물 건설
23) 감옥 기능 (주사위 더블로 나갈 수 있어야함 아니면 일정한 재화를 지급 후 나가야함)

제작중인 기능
1) 찬스칸에 도달 시 즉시 실행 카드와 보관 후 나중에 쓰는 카드 (카드 덱 / 보관함)
2) 여행 기능 (부루마불 세계여행)
3) 내 Pawn이 시작칸에 도달 시 내가 구매한 땅들 중에 딱 한 지역에 건물을 올리는 기능
4) f1, f2 번을 눌려서 찬스칸 이동 감옥 칸 이동 등 테스트 전용 이동 키 기능
5) 게임 승리조건 기능

오류 수정 사항 - 게임 플레이 할 때 큰 오류 사항 아님(부루 마불 게임 승리 & 패배 기능 구현 완료 후 수정할 사항)
